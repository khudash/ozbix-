How to Connect PostgreSQL (postgray.sql)

1 Install & Start PostgreSQL Service

Ensure PostgreSQL is installed on your system (e.g. pgAdmin or PostgreSQL server running on port 5432).

2 Create Database & Run postgray.sql

Run the provided postgray.sql script in psql or pgAdmin: 

psql -U postgres -c "CREATE DATABASE ozbix_db;"
psql -U postgres -d ozbix_db -f postgray.sql
3 Run Django Migrations 
python manage.py migrate
